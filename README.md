# weekly-food-planner
Weekly Food Planner is a locally hosted, Docker-based meal-planning application designed to make healthy eating simple and sustainable. It helps users organize weekly meals, build grocery plans, and make nutrition-conscious choices while using an integrated AI dietitian to provide personalized meal suggestions, nutrition guidance, and planning assistance.
The app is designed to combine meal planning, nutrition tracking, grocery organization, and AI-powered recommendations in one private, self-hosted platform—making it easier to maintain healthy eating habits without relying on multiple apps or complicated calorie tracking.
